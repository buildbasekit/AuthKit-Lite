# AuthKit-Lite

A minimal Spring Boot authentication foundation with JWT, refresh-token rotation, role-based authorization, and optional passkeys.

## Included

- JWT access tokens

- Rotating refresh tokens

- Role-based authorization

- Optional WebAuthn/passkeys

- Spring Security OAuth2 Resource Server

- H2 + Flyway development setup

- MySQL support

- Postman collection and integration tests

- AI-ready project context

## Quick start

```bash
git clone https://github.com/buildbasekit/AuthKit-Lite.git
cd AuthKit-Lite
./mvnw spring-boot:run
```

Runs with H2 by default. No external database setup is required for the first run.

→ **[Quickstart guide](https://buildbasekit.com/docs/authkit/quickstart/)**
